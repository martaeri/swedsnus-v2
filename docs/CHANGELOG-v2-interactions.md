# V2 interaction follow-up

This follow-up adds the interaction details requested after the initial V2 foundation was merged:

- login modal for protected saved-product flows;
- separate saved/cart count badges;
- bookmark icon and active bookmark state;
- centralized prototype multipack selector with total and per-unit display;
- three restrained palettes with cool blue/grey as default;
- warm beige/brown and muted green alternatives;
- theme persistence across pages.

The multipack pricing is demonstrative only. Replace the calculation with mapped product/PIM tier-price data when those fields are available.
