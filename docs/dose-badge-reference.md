# Dosmarkör på produktkort

Dosmarkören följer den visuella referensen från 2026-09-28:

- placeras kant i kant nere till höger på produktbilden
- använder temats mörka accentfärg som bakgrund
- använder den bifogade vita `assets/dosor-icon.svg`
- visar `amount_dosor` i Montserrat Bold till höger om ikonen
- ligger visuellt i samma höjd som styrkemarkören på motsatt sida
- skalas ned på mobil utan att ändra informationshierarkin

Dosantalet hämtas fortsatt från produktdatan och visas endast när `amount_dosor` finns.
